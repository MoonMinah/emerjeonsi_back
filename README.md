# emerjeonsi
🖼공공전시 티켓 예약 사이트 프로젝트입니다.🎫


## 📌프로젝트
### 소개
- 지역 문화 정보 불균형을 해소해보고자 만든 프로젝트입니다.
- 공공데이터를 통해 가져온 전국의 공공전시를 예매할 수 있어요.

### 기능 소개
회원가입/로그인  
- spring security를 통한 인증/인가
- 로그인시 회원/관리자 구별되어 페이지로 이동합니다.
  
마이페이지  
- 정보수정, 회원퇄퇴가 가능하며 회원탈퇴시 논리삭제로 구현하였습니다.
    
관리자 페이지
- 연령별, 성별 인기 전시를 볼 수 있어요
- 전국의 공공전시를 관리할 수 있어요.
